# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/KingInYellows/yellow-goal/security/advisories/new).
Do not open a public issue for a vulnerability.

Include the affected version of `goal-gen`, the steps to reproduce, and the
impact you expect. You should get a first reply within a week. This is a
one-maintainer project, so fixes ship on a best-effort basis.

## Scope

In scope: `goal-gen` (its CLI, runner, executors and approval gates) and the
workflows in this repository.

Out of scope: the coding agents that `goal-gen` drives, such as Claude Code
(report those to their vendors).

## Supported versions

Only the latest release receives fixes.
